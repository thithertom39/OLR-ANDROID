# OLR-Android

**Old Lost Reborn on Android.**

An Android adaptation of **S.T.A.L.K.E.R.: Oblivion Lost Remake**, bringing the atmosphere of the Zone to mobile devices.

Built on the Android port of the X-Ray engine by **Eternal Entropy**, with additional modifications, optimizations, and a custom launcher.

## Features

- Native Android support
- Custom launcher and touch controls
- OpenGL ES rendering
- Performance and stability improvements
- Ongoing development
