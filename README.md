# OLR-Android


An Android adaptation of **S.T.A.L.K.E.R.: Oblivion Lost Remake 2.5**, bringing the atmosphere of the Zone to mobile devices.

<img width="3620" height="2036" alt="YpoFdkOPReNkwlMQgEhplw (1)" src="https://github.com/user-attachments/assets/62c896cb-4592-40e6-a031-94546c322ec8" />



## Features

- Native Android support
- Custom launcher and touch controls
- OpenGL ES rendering
- Performance and stability improvements
- Ongoing development
